# Superstore Sales Analysis Dashboard

## About the Project

This project was completed as part of a Data Analytics Internship. The goal was to perform end-to-end sales analysis using Excel, SQL, and Power BI and derive meaningful business insights from the Superstore Sales dataset.

## Skills Demonstrated

* Data Cleaning
* Data Analysis
* Pivot Tables
* SQL Querying
* Data Visualization
* Dashboard Development
* Business Reporting

## Tools & Technologies

* Microsoft Excel
* SQL Server Management Studio (SSMS)
* Power BI
* GitHub

## Project Deliverables

### Excel

* Data validation
* Summary metrics
* Pivot table analysis

### SQL

* Sales analysis queries
* Profitability analysis
* Monthly trend analysis

### Power BI Dashboard

* KPI Cards
* Sales by Region
* Monthly Sales Trend
* Category Distribution
* Top Customers Analysis
* Interactive Filters

## Key Results

* West region achieved the highest sales.
* Technology category generated the highest profit.
* High discounts negatively impacted profit margins.
* November was the best-performing month.
* Top customers contributed a large share of total revenue.
